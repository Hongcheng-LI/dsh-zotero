# 结构化文献精读

把一篇文献读成可复用的结构化笔记。配合 `tool-zotero` 插件（zotero_search / zotero_item / zotero_fulltext / zotero_notes 工具）使用。

## 步骤

1. **定位条目**：`zotero_search`（标题关键词/作者/年份）→ 拿到 itemKey；不确定时先 `zotero_recent` 看最近导入。
2. **读元数据**：`zotero_item`（itemKey）→ 作者、期刊、DOI、摘要、附件列表。
3. **读全文**：`zotero_fulltext`（itemKey）→ 纯文本全文（超长时分段消化，先读摘要+图表标题+结论段）。
4. **提取要点**（生命科学/合成生物学模板）：
   - 研究问题与假设
   - 关键方法（菌株/质粒/酶/检测手段）
   - 主要结果与数据（活性数值、产量、统计显著性）
   - 结论与局限
   - 与用户课题的关联点（可选，问用户要不要）
5. **存档**：把要点整理成笔记，经用户确认后写入（注意：多数版本本地 API 只读，`zotero_note` 写入不可用时会明确报错，此时把笔记输出到对话或保存为工作区 Markdown 文件 `notes/<citekey>.md`）。

## 原则

- 摘要里的结论必须回原文核实，不得凭摘要推断数据细节。
- 活性/产量数值必须带单位与条件（菌株、底物、培养条件）。
- 输出格式固定，方便多篇对比与后续综述。
